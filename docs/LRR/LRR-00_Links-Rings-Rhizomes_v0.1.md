# リンクとリングの政治経済学／考古学｜研究構想 v0.1

Nov 28, 2026 · @一狄翁

## 出発点

共通の問いは「接続をどこまで制度化する必要があるのか」。まだ論考ではなく、研究構想と発掘調査の観測軸の段階である。

2026-11-28、別番組「公開ダラダLIVE」で一狄翁が喋っているうちに出てきた違和感が起点になった。旧来のブログ型を除くと、最近のウェブはタイムライン・アルゴリズム型SNSと、Substack・Patreon・LISTENのような購読・囲い込み型に分かれてきている。Digital Garden・IndieWeb・分散型という第三の道はあるが、庭どうしがうまくつながりきれていない。

これは出発点の違和感であって、検証済みの現状認識ではない。第三の道は本当につながりきれていないのか。それとも、つながりきることを前提にしている観測者の側に問題があるのか。後者の可能性も残しておく。

### 設計思想としての命題：接続は管理できない

第三の道は、リンクの極とリングの極の中間に、よりよい接続管理の方式を探すことではない。接続を管理するという共通の前提そのものを問い直すことである。

接続は管理できない。管理できるのは、接続の条件や、制度化された関係や、接続に伴う痕跡であって、接続そのものではないのではないか。リンクがあっても遭遇しない。リンクがなくても遭遇する。購読を解除しても関係は続き、購読を続けていても関係は途絶える。

これは歴史研究から得た結論ではなく、DyXis の設計思想として置く命題である。その射程と限界も、研究の観測対象とする。DyXis 自身も nest.json の札、私書箱の入居、Issue とラベルを管理している。これらは接続の痕跡と条件である。DyXis が管理するのは痕跡と条件だけ、と言える状態を保つことが、この命題の守り方になる。

「アリは並ばない」（一狄翁）。並ぶことはある。列から外れることもある。別の列に遭遇することもある。しかし、列がアリを定義するわけではない。地図は描ける。だが、地図は農場ではない。

この構想は二本立てで進める。

- 現代篇｜リンクとリングの政治経済学（The Political Economy of Links and Rings）── 注意の集中と所属の囲い込み
- 歴史篇｜リンクとリングの考古学（The Archaeology of Links and Rings）── 分散型ウェブの試みは何を抱え込んできたのか

構想の分担：問題提起と「リンクとリング」の一語は一狄翁、五つの営み・時間の制度化・三つの観測軸の整理は響詠、事実確認と監査は綴音。

## 現代篇：リンクとリングの二極

仮説：いまのウェブは、注意を集める「リンクの極」と、所属を集める「リングの極」に分かれている。これはプラットフォームの厳密な分類ではなく、二つの方向への極化を捉えるための整理である。

|  | リンクの極 | リングの極 |
| --- | --- | --- |
| 典型 | タイムライン型SNS | 購読・会員型（Substack・Patreon・LISTEN） |
| 接続の原理 | フォロー・推薦・拡散 | 購読・所属・支払い |
| 過剰化の形 | 接続の増殖 | 囲い込みの増殖 |
| 管理するもの | アルゴリズム | 会員・権限の管理 |
| 希少なもの | 注意 | 所属とアクセス |

実際のサービスは両方を併せ持つ。Substackにもタイムラインがあり、SNSにも会員制がある。問題は、両者が混ざりながら過剰化していることだ。

ブログロール（リンク）もウェブリング（リング）も、もともとは巨大プラットフォームなしで成り立つ接続のしかただった。問題はリンクやリングそのものではなく、リンクの管理が集中し、リングの境界が強まったことにある。

## 第三の道と五つの営み

第三の道の弱さは「見つけ方」にある。自分の庭は持てるが、庭どうしの道が細い。分散型SNSも、結局はフォローでつながっている。

Digital Garden・IndieWeb・分散型SNSを一括りにせず、接続を次の五つの営みに分けて考える。五つは本来別々の営みだが、ソーシャルウェブの構想はこれを一つの仕組みで実現しようとする傾向があったのではないか（検証すべき仮説）。

| 営み | 時間的な性質 | DyXis周辺での担い手 |
| --- | --- | --- |
| 自分の場所を持つ | 持続 | 自分の巣（自前のサイト、CHIC TEC の私書箱） |
| 他者の場所を知る | 発見 | nest.json の札 |
| 他者の場所を訪れる | 遭遇 | nest.json の札 |
| 関係を維持する | 継続・断絶・再遭遇 | 仕様にしていない |
| 更新を受け取る | 非同期的な到来 | LiRax・REC-G（RSS） |

「関係を維持する」が空欄なのは、営みがないからではない。関係は生じてもよいし、続いても、途切れても、忘れた頃に再遭遇してもよい。その時間的な推移をシステムが管理しない。ここに Synchro-Lag の意味がある。

既存のSNSでは、一度の遭遇がフォローという持続的な関係に変換される。購読型では、関心が継続的な購読契約に変換される。一回的な遭遇を持続的な制度関係へ変換することを必須としない点に、DyXisの実験的な意味があるかもしれない。

## 三つの観測軸

リンクとリングの問題は、空間と関係だけでなく時間の問題でもあった。発掘する各事例を、次の三つに分けて観測する。

- **空間の制度化**：場所・境界・所属を誰が管理するのか。
- **関係の制度化**：接続・承認・継続を誰が管理するのか。
- **時間の制度化**：更新・通知・順序・再遭遇を誰が管理するのか。

各事例について、管理する主体だけでなく、管理の外に置かれたものも記録する。右の列は観測の候補である。

| 観測軸 | 管理するもの | 管理しないもの（候補） |
| --- | --- | --- |
| 空間 | 場所・境界・所属 | 自由な往来 |
| 関係 | 接続・承認・継続 | 断絶・偶発的な遭遇 |
| 時間 | 更新・通知・順序 | 遅延・忘却・再遭遇 |

制度が何を可能にしたかだけでなく、何を制度の外に残したかを観測する。制度の考古学であると同時に、余白の考古学でもある。

あわせて、各事例の「重さ」を四つに分けて記録する：技術的負荷、組織的負荷、思想的対立、普及の条件。「盛り込みすぎたから倒れた」という結論を先に置かない。

これは観測仮説である。歴史的な事例を、この構文に無理に押し込まない。

## DyXis の位置：何をしないか

DyXis はこの研究の結論ではなく、現在進行形の実験標本として置く。歴史は DyXis を正当化するためではなく、DyXis 自身が同じ坂を転げ落ちる可能性を観測するために掘る。

DyXis の札は、接続に付いてきた機能を切り離している。

- 札を立てても、フォロー関係は成立しない。
- 札を読んでも、会員にはならない。
- 隣の巣を訪れても、その更新を受け取り続ける義務はない。

つながることと、つながり続けることは違う。

DyXis の軽さは接続の数を減らすことから来るのではない。接続が増えても、その全体を管理する主体を必要としないことから来る。巣も施設も増えてよいが、それらを DyXis の必須機能として抱え込まない。生態系は豊かに、仕様は小さく。

先祖との対比（比較仮説。ブログロールも OPML で機械可読にでき、ウェブリングの実装も一様ではない）：

- ウェブリングには輪を管理する親がいる。DyXis の札には中心がない。
- ブログロールは書き手の好みの一覧だが、nest.json は機械が読める形で次の巣へ渡っていける。
- Tent は各人のプロフィール JSON をサーバーとプロトコルでやりとりした。nest.json は置くだけの静的なファイルで、通知もない。
- SWWG で RDF 派が退けた「最小限のプロフィールで友人を数人宣言する」案は、nest.json の札に近い。

## 追記｜集権・分権と閉包・非閉包

2026-11-28

集権／分権だけでは、接続をめぐる管理の問題を捉えきれない。

集権／分権は、管理権限の配分の問題である。閉包／非閉包は、管理の射程と、管理対象の総体化をめぐる問題である。

両者を区別し、さらに管理可能性そのものを問う。

|観測軸|問い|
|---|---|
|管理の配分（集権／分権）|誰が管理するのか|
|管理の射程（閉包／非閉包）|何をどこまで管理するのか|
|管理可能性|そもそも何が管理できるのか|

分権化は、必ずしも非閉包化を意味しない。管理権限が分散していても、接続の総体を管理対象とする構文は残りうる。

逆に、局所的な集権や閉包が存在しても、接続の総体が閉包されるとは限らない。

**局所的な閉包と、全体の非閉包性は両立しうる。**

DyXis の設計思想は、管理権限の分散だけではなく、管理の射程と管理可能性そのものを問い直すところにある。

接続は管理できない。管理できるのは、接続の条件や、制度化された関係や、接続に伴う痕跡であって、接続そのものではない。

以上は研究上の観測枠組みと設計思想であり、歴史研究によって得られた結論ではない。閉包／非閉包の概念規定も、今後の検討に開いておく。
