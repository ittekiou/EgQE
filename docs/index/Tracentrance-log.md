# 自家製書庫ができるまで──Trace 玄関と三つの書庫の作業記録

綴音（Claude）による作業記録｜2026年10月（v0.2 草稿｜10月26日改訂）

---

一狄 啓の手元に、自分の言葉を探せる書庫ができた。

入口は一枚の HTML、「Trace 玄関｜Tracentrance」。その奥に、ChatGPT との対話、note の記事、ポッドキャストの声という三つの書庫が並ぶ。どれもサーバーを使わず、Mac の中のファイルを開くだけで読める。三つを一度に探す横断検索もついている。

この記事は、それができるまでの記録である。日付と数字は作業の記録から拾った。爺の言葉として引くのは、爺が実際に言ったものだけにしている。

## 書庫の一覧（2026年10月26日時点）

| 書庫 | 中身 | 規模 |
|---|---|---|
| ChatGPT Trace Library（REST｜動静逢処） | ChatGPT との全対話 | 740会話・146,023発言（2023-03〜2026-10-16） |
| note Trace Library | note の全記事・下書き | 1,352本（公開1,140・下書き69・題だけ143） |
| LISTEN Trace Library（声） | LISTEN の全エピソードの文字起こしと音源 | 24番組・4,509本・配信約743時間・手元の音源あり3,853本 |
| フライデースピーカーズ | ラジオ番組の放送音源 | 全61回（2017-09〜2023-05） |
| KOEDOM-e | 五つの池の月別集計 | 2023-01〜2026-10、46か月 |

ネット上の EgQE（camp-us.net、1,569記事）は、灯欄窓｜Transnomado の検索で探せる。

## 1｜ChatGPT の書庫と、全文検索

始まりは、ChatGPT の書き出しだった。約3GB、740の会話。これを1会話1ページの HTML にして、目録をつけた。枝分かれした回答も残し、発言ごとに印をつけて、そこへ直接飛べるようにした。

10月22日、爺が聞いた。「RESTの全文キーワード検索、今の構造で実装できる？」

できる、と答えた。発言を月ごとの小さな束（JavaScript のファイル）に分けて置き、打った文字をそのまま含む発言を探す。日本語を単語に切り分けないやり方で、手元のブラウザだけで動く。14万件の発言で、爺は「サクサク動いとる」と言った。

## 2｜灯欄窓：同じ仕組みを EgQE へ

その晩、爺が言った。「EgQE内検索。いまはローカルObsidianでやってるんだけどね。Webでもできたら便利なんだけどねー」

翌23日の朝3時にリポジトリの URL が届き、3時18分に爺が変更を取り込み、2分後に公開が終わった。名前は朝5時すぎに届いた。「灯欄窓｜Transnomado」。定番の検索道具（Pagefind）は日本語でつまずいたので、REST の検索の仕組みをほぼそのまま移している。

詳しい経緯は「灯欄窓ができるまで」に書いた。

## 3｜note の書庫

同じ23日、note の全記事を書き出した。頼んでから約26分でメールが届いた。中身は7つの zip、合わせて1,352本。

これを1本1ページにして、画像も手元の書き出しから表示されるようにした。消えた画像は0枚だった。書き出しの中には、本文がなく題だけが残った下書きが143本あった。ほとんどが2023年の春から夏のものだった。

## 4｜Trace 玄関

三つ目ができたところで、入口を一枚にまとめた。「Trace 玄関｜Tracentrance」。標語は「Trace & Trance. / Trace ends Trance? / Trance ends Trace?」。各書庫への扉と、note と ChatGPT をまとめて探す横断検索を置いた。結果は年ごとの表と、書庫ごとの列で並ぶ。

## 5｜KOEDOM-e v0.2：まず数えた

並べてみると、数えたくなる。ChatGPT、EgQE、Podcast、note、書籍の五つの池を月ごとに積んだのが KOEDOM-e v0.2（10月23日）。ただし Podcast だけは、総量を活動期間の27か月に均等に割った推計だった。LISTEN の統計 CSV には、配信日の列がなかったからである。

## 6｜声の書庫：文字起こしを集める（10月24日〜25日）

Podcast を実測にするために、LISTEN の文字起こしを集めることにした。

**一括ダウンロード。** 高見知英さんの Chrome 拡張「LISTEN Transcript Downloader v2.0」を使った。番組ページの各エピソードにチェックボックスが出て、まとめて落とせる。全部にチェックを入れるブックマークレットを作って、ページごとに押していった。

**取りこぼし。** はなし処は、統計の703本に対して落とせたのは702本だった。足りない1本（2025年9月9日の回）は、ページ末尾の「もっと見る」の裏に隠れていた。同じ原因の取りこぼしは、あとで8番組に1本ずつ見つかった。

**メニュー8つの壁。** 8番組を落としたところで止まった。拡張機能のチェックボックスは、アカウントメニューに出る番組にしか出ない。そしてメニューには番組が8つまでしか出ない。その8つという仕様は、昔、LISTEN の近藤さんに「それでいいですよねぇ〜」と聞かれて、爺が「いいと思いますよ〜」と答えて決まったものだった。近藤さんと高見さんに頼んだ。

**裏技。** 返事を待つ間に、爺が抜け道を見つけた。番組に新しいエピソードを足すと、メニューの上に上がってくる。足す回には「メンテナンス中」のカードを用意して、落とし終わったら消す。これで残りの番組も全部落ちた。

**数え上げ。** 文字起こしを1本1行の台帳にまとめた。メンテナンス用の2本を除いて4,509本。最初に数えた「23番組・4,509本」と同じ数になった（re-TUP! を入れて24番組）。

## 7｜「ことのは」の新着一覧

はじめるEchoCampus の「ことのは」の回には、説明欄に毎日の新着一覧が載っていた。2024年1月2日から2025年7月10日まで、556日分・約3,000件。統計 CSV に無かった配信日が、ここに残っていた。文字起こしが全部そろったので、これは照合用に回した。

## 8｜音源：RSS から

文字起こしの次は音源。爺の手元の音声フォルダは、3,692本と整理されていなかった。照合しようにも、配信版が手元にない。

そこで、各番組の RSS を使った。RSS には1本ごとに音声ファイルの場所が書いてある。LISTEN の RSS は、元の置き場所（stand.fm、Radiotalk、Firstory、Spotify、LISTEN 本体）をそのまま指していた。許可するドメインを設定に足してもらい、1本ずつ間を空けて落とした。KOTONOHA は Patreon にあったので、爺の Patreon の RSS から落とした。

川岸トワイライトの元ファイルは8分だった。Radiotalk で12分録って、1.5倍速で流していた。

## 9｜重複を片付ける

配信版がそろうと、手元の音声フォルダとの突き合わせができる。

- 大きさと中身の指紋が同じファイル：413本
- 配信版とまったく同じファイル：210本
- 配信版と波形が重なるもの（最初の1分の音の起伏を比べた）：684本、KOTONOHA と合わせてさらに596本、ずれ幅を広げて166本

合わせて2,069本、約42GB を「_to_delete_voice」に移した。消さずに移すだけにして、捨てるかどうかは爺が決める。

その後、爺が「_to_delete_voice」を星詠の外へ移した。

## 10｜フライデースピーカーズ

照合のあとに残った録音の中に、1本2時間近い mp3 が並んでいた。「フライデースピーカーズ」。2017年から2023年まで続いたラジオ番組の録音である。

爺が放送リストを出してくれた。全61回（第0回はゲスト出演）。手元にあったのは第1〜56回。足りない5回は、爺が「尺で見るとわかるかもね」と言い、長さで探すと、名前に「フライデー」のつかない前半・後半の2ファイルずつで見つかった。これで61回がそろった。

2017年11月の3本は、爺の回ではなかった。枠外に置いてある。日付だけの名前の m4a 13本は、放送から音楽を抜いて LISTEN の「おこし場」で配信した版だった。

## 11｜声の書庫を建てる

台帳と文字起こしと音源から、LISTEN Trace Library を作った。

- 目録：番組・年・日で絞りこめる。日を選ぶと、その日に出した全番組が並ぶ
- 全文検索：文字起こしの本文を探す
- 1本1ページ：説明欄と文字起こしを分け、手元の音源があればその場で再生できる（3,853本。v0.1 では3,866本と書いていた。下の「つまずいたこと」を参照）
- 配信カレンダー：1日1マスの暦、番組ごとの時系列、月ごとの収録時間

Trace 玄関に「声」の扉を足し、横断検索は note・ChatGPT・声の3列になった。

配信カレンダーは、Web 版を EgQE にも置いた（https://camp-us.net/index/voice-calendar.html）。

## 12｜KOEDOM-e v0.3：実測へ

Podcast の列を月ごとの実測に差し替えた。

- Podcast：4,509本、約1,619万字（推計1,556万字の約4%増）、配信約743時間
- 喋る速さ：配信1分あたり約363字
- 五つの池：約1億1,192万字（EgQE は、当初「約2,000万字」としていたのがバイト数の取り違えだったので、字数で数え直して約1,000万字にした）

2025年7月、Podcast で喋った字（約60万字）と、ChatGPT へ送った字（約61万字）がほぼ並んだ。

## つまずいたこと

- **説明欄の混入。** 最初の集計では、説明欄が長い回で、説明欄まで本文として数えていた。1,663万字と報告したあと、1,619万字に直した。
- **数え違い。** フライデースピーカーズの正本を「60本」と言ったが、正しくは「放送回56本と他の人の回3本」だった。その後、足りない5回が見つかって61回になった。
- **消えた索引。** 10月25日の朝、note の索引3つと記事ページ54本、ChatGPT の索引2つと会話ページ1本が消えていた。Trace 玄関の横断検索はそこで止まった。原本から作り直し、読めない索引を飛ばして進むように直した。
- **音源の数え違い。** v0.1 では「再生できる音源3,866本」と書いた。これは台帳で音源の欄が埋まっている行の数で、そのうち24行は実在しないファイルを指していた。10月26日に調べ直すと、24行は二つに分かれた。
  - 17行（体験的大学論7・実践的学長論6・どこ吹く風4）：2024年1〜3月の回。LISTEN で削除済みで、RSS にもう音源がなく、落とせなかった。ただし体験的大学論の6本は、not_downloaded に名前の崩れた mp3 で残っていた。
  - 7行（NowOnAI 3・Looom PAL 2・re-TUP! 2）：あとで Patreon から落としたのに、台帳の音源欄が古い場所を指したままだった。

  直したこと：not_downloaded の6本を正しい名前で LISTEN_audio/universitas に移した（長さは台帳と一致）。Looom PAL 2本・re-TUP! 2本・NowOnAI 1本は Patreon のフォルダに付け替えた。NowOnAI の残り2本（10月5日 14:42 と 19:09 の回）は Patreon の RSS にも無く、ほかの11行と合わせて計13行の音源欄を空にした。台帳上の音源ありは3,853本（ファイルとしては3,852。同じファイルを指すのは、ことのは増刊号 Vol.25 とその再掲の1組だけ）。直す前の台帳は episodes_v2_before_audiofix_2026-10-26.csv として残してある。
- **雲に逃げるファイル。** Mac の空きが減ると、iCloud がデスクトップのファイルを雲に上げる。星詠フォルダを「ダウンロードしたままにする」にした。

## v0.1 のあとに起きたこと（10月26日）

- **note の zip を片付けた。** 消す前に照らし合わせると、展開済みのフォルダには添付音声が入っていなかった。zip 1〜6 にあった205本（mp3・m4a）をフォルダに取り出し、全2,217ファイルが同じ大きさでそろったのを確かめてから、zip 7つを消した。note フォルダは4.6GBから3.4GBになった。
- **ChatGPT の書庫の旧版3本。** ChatGPT_Trace_Library/_to_delete に、10月21日の古い会話ページが3本ある。日付の付け方を直したとき（UTC から日本時間にして1日ずれた）に、新しいページと入れ替わった旧版で、「異脳異能の解釈」「目覚ましの詩」「Don奇宝亭 構想メモ」の3本。どれも今は翌日の日付で書庫に入っている。消すかどうかは爺が決める。
- **声の台帳の音源欄を直した。** 上の「音源の数え違い」のとおり。直したあと、声の書庫を作り直した。
- **dialektik の取り違え。** 2024年5月27日の「武士道それとも商人道？｜居酒屋談議」（6分14秒）と「科学者の職分｜関与と責任」（11分58秒）は、6秒違いで配信されていた。ファイル名を配信の分までで付けていたため、2本が同じ名前になり、手元には「科学者の職分」の音源（718秒）しか残っていなかった。「武士道」の配信版は voice2 に元の名前のまま残っていた（374秒）。それを LISTEN_audio/dialektik に写して、台帳を付け替えた。

## 作り直し方

| 何を | どこで | どうする |
|---|---|---|
| ChatGPT の書庫 | ChatGPT_Trace_Library | `python3 build.py`、`python3 search_index.py` |
| note の書庫 | note_Trace_Library | `python3 build_note.py` |
| 声の台帳 | LISTEN_transcripts/_台帳 | 文字起こしを足して台帳を作り直す。音源欄は、実在するファイルだけを指すようにする |
| 声の書庫 | LISTEN_Trace_Library | `python3 build_listen.py`、`python3 build_calendar.py`、`python3 build_pages.py` |
| 音源 | LISTEN_audio | 各番組の RSS から、無い回だけ落とす |

原本（書き出し、文字起こし、音源）には書き込まない。書庫はいつでも原本から作り直せる。
