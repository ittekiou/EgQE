## 4. ひとことで言えば

- **修論**は、ミルズを「社会的ラディカル」として描く**人物＝政治論**。知識社会学の読解は、「なぜ彼は絶望しなかったのか」「なぜ自己統治が社会統治に通じるのか」を支える材料として使われている。
- **助手論文**は、同じ最初期を**認識論・言語論として掘り直した**もの。草稿という新しい資料を得て、パース／デューイ／ミードとの格闘を正面から扱い、語彙も「〈社会〉」「相対論」「ゆらぎ」「〈言語化〉」といった90年代の語り口に変わっている。
- 共通して残っている芯は、**存在被拘束性の自覚 → 意識的・能動的な選択 → 自己教育的な存在**という筋。修論の「主体化の論理」が、助手論文では「思考の意識性・能動性」「思想のラディカリズム」と呼ばれている。
