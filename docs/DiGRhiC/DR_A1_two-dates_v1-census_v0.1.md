
# 庭解剖探検隊｜A 二日付制の普及史（V1）集計 v0.1

**記録日：2026-11-19｜作業：綴音（読み取り専用のclone上で集計）｜状態：Open**
**上位プロトコル：v0.3 Fixed（変更なし）**

## 0｜対象と方法

- 対象：V1候補 `MaggieAppleton/maggieappleton.com`、`master` ブランチ（最終コミット 2021-10-22）。原本には手を触れていない。
- 範囲：`content/notes/` と `content/notes-drafts/` の `.md`／`.mdx`。マージコミットは除外し、ファイル移動は追跡した。日時は作者時刻（元のオフセット付き）。
- 判定：各原稿で、frontmatterに `startDate:` が**初めて現れた**コミットを「導入」とし、直前の状態（親コミット）と比べて型を分類した。
- 検算：`git log -S 'startDate:'` は20件。導入コミット19件と、`tools-for-thought` を drafts へ移した1件（9d0b98f）で一致。`git log -G '^startDate:'` は24件で、上の20件に値の書き換え4件を足すと一致。

## 1｜結論（観測事実）

1. **V1では、二日付制は庭全体に行き渡らなかった。** 最終状態（2021-10-22）の `content/notes/` の原稿74本のうち、`startDate` を持つのは21本。53本は `updated` だけ。
2. **導入は一斉ではなく、一本ずつ。** 期間は2021-01-15〜08-25、計22本（うち1本はのちに drafts へ移動）。
3. **導入の仕方は一つではない。** 下の型が混在している。

| 型 | 本数 | 定義 |
| --- | --- | --- |
| 新規遡及 | 5 | 旧日付を `updated` に残し、それより前の `startDate` を新たに宣言 |
| 継承遡及 | 2 | 旧日付を `startDate` に回し、新しい `updated` を宣言（roam-garden 型） |
| 同日型（旧値を両方に） | 1 | 旧日付を両方に入れた |
| 両方新規 | 4 | `startDate` も `updated` も旧日付と異なる値 |
| 作成時から・同日 | 5 | 新規ファイルで、両日付が同じ |
| 作成時から・別日 | 3 | 新規ファイルで、`startDate` が `updated` より前 |
| 作成時から（startDateのみ） | 2 | 新規ファイルで、`updated` がない（Planted だけが表示される形） |

月別の導入本数：2021-01｜6、02｜2、03｜2、04｜4、05｜2、06｜1、07｜4、08｜1。

## 3｜付随して確定したこと

- **1月15日は三段だった。** 08:46 表示機構（`c82e2e7`）→ 09:05 一斉改名と artisan-data（`77fa865`）→ 09:46 さらに4本（`b7ba040`「updated many posts」）。同日の導入は計5本。響詠報告の「77fa865 内の startDate 追加は1件」は正しく、同日の別コミットにあと4本ある。
- **タイムゾーン説は消えた。** `a37d58f` の元の記録は 2021-07-04 22:50:14 +01:00。現地でもまだ7月4日。宣言された `updated: 2021-07-05` は、記録時刻の翌日を指している（理由は未判定）。
- **startDate も書き換えられている。** glitter-devs（2021-03-17：03-13→03-17、18分後に03-13へ戻す）、xanadu-patterns（2021-06-12：07-10→07-12、13分後に07-10へ戻す）。いずれも直後に元へ戻っている。

## 4｜留保

- `master` に入っていないブランチ上の変更は数えていない。
- 「74本」は `content/notes/` 内の `.md`／`.mdx` の機械的な数で、`0_frontmatter-placeholder/index.md` や `FAQ.mdx` のようなノートでないものも含む。比率を出すときは分母を整える必要がある。
- 型の判定は frontmatter の値の比較だけによる。著者の意図は判定しない。
- 「両方新規」の4本は、旧日付との関係を一本ずつ見る余地がある。
- V2への取り込み（2021-09-25）で、残り53本に `startDate` が付いたかどうかは未調査。V2では Notes の `startDate` が必須なので、移行時に一括で付けられた可能性がある。次の地層の候補。

## 5｜仮説の欄（事実ではない）

- 08:46 の表示機構導入と 09:05 の artisan-data の関係は、仮説のまま保留。ただし同日 09:46 にさらに4本続いたので、「一本だけ試した」というより「その朝に何本か手を入れた」に近く見える。
