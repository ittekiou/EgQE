## 1｜V1｜表示機構と個別導入（2021年）

2021-01-15に表示機構が入り、`startDate` の導入は一本ずつ進んで22本（2021-01〜08）。導入の型は一様ではなく、継承遡及・新規遡及・両方新規・作成時からなどが混在する。V1最終状態では、`content/notes/` 74本のうち21本だけが二日付。

→ [DR_A1_two-dates_v1-census_v0.1.md](DR_A1_two-dates_v1-census_v0.1.md)

→ [DR_A2_v1-to-v2_migration_v0.1.md](DR_A2_v1-to-v2_migration_v0.1.md)

## 3｜V3｜継承と表示規則（2024年〜）

複写された42本からFAQを除く41本のうち、29本は複写値のままV3現在まで残る。変化はすべてV2時代に起きた。V3の表示部品は、同じ日付の Last tended を出さない。V3最初の作業版（2024-12-04）では、notes・essays・patterns の二日付はすでに必須。essays へ移った18本のうち9本は、V2の途中で notes へ戻った。

## 4｜時計の移動｜V2からV3へ

| | V2（2024-11-03〜） | V3（2024-12〜） |
| --- | --- | --- |
| 原稿 | `<YearsAgo>2020</YearsAgo>` | 同じ |
| 計算する場所 | 読者のブラウザ（`dynamic(..., { ssr: false })`） | 静的ビルド |
