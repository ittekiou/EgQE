## CABA / TUP Memo｜光・影・Editus

### 2026-09-16 夕方散歩

### 1｜出発点

朝メモでは、Cedorbity と Activity の関係について二つの向きが揺れていた。

`Activity as Cedorbity Shadow`  
`Cedorbity as a Shadow of Activity`

夕方散歩では、後者、

> **Cedorbity as a Shadow of Activity.**

へ傾いた。

ただし、これは `Cedorbity = Activityではない何か` という二項対立を立てることではない。

**影は物ではない。光との関係で現れる。**

したがってCedorbityも、Activityの反対側に存在する未知の実体や内部機構として置かない。

`Shadow ≠ Content-free Placeholder`

影は空語ではない。光との関係によって輪郭を持つ。  
しかし、

`Shadow ≠ Hidden Substance / Mechanism`

でもある。

### 2｜Arendt / Han / Bourdieu

当初は、

- Arendt → Action
- Han → Inactivity
- Bourdieu → Habitus / Practice / BODY
- われわれ → Editing? / Edited? / Updating?

という横並びに見えた。

しかし、この配置は修正が必要。

ArendtのActionとHanのInactivityは、人間の営みをどのようなカテゴリー／価値として見るかという問題に近い。

BourdieuのHabitus / Practice / BODYは、それとは異なり、

> **実践はいかにして現在の実践になるのか**

という生成・媒介の側へ踏み込んでいる。

今回のHabitus ProbeでBODYを開いた結果、残ったのは、

> `Site of Mediation ≠ Mechanism of Mediation`

だった。

したがって、CedorbityはArendt / Han / Bourdieuに並ぶ「第四の答え」ではない。

むしろ、

> **BourdieuのHabitus / Practice / BODYを開けたあとに残った `[ ? ]` の縁に現れている語**

として位置づけるほうが現在の軌道に忠実。

---

### 3｜HOWの現在配置

矢印を使わない。

TUP-01ですでに、`A → B` は単なる中立的記法ではなく、順序・再度性、場合によっては因果まで密輸入しうることを確認している。

したがって現在は、観察できる前後を**配置するだけ**に留める。

```
HOW眺め / interface
Encounter / rate-lag / otherness

HOW拾い / ingestion
input / trace

HOW詠み / 編集する？
[ ? ]
Cedorbity ｜ Activity
internalized other

HOW綴り / excretion
output / trace
Editus
```

ここで重要なのは中央。

> **HOW詠み / 編集する？**

`editing / edited / updating` は、中間で何が起きているかを説明する機構名としては使わない。

**中身なしでよい。**

ただし、この「中身なし」自体も今回初めて獲得した作法ではない。

すでに、

`AI ?_editus`

`Homo editus ?_relation AI editus`

`Updating ?_HOW 消え現れ`

という形で、**`?` を等号で埋めない作法**は使われていた。

今回の

`Editing? / Edited? / Updating?`

も、その系列にある。

---

### 4｜Editing監査は撤回しない

01Dでは、

> `Different Subsequent Work of a Prior Trace ≠ Editing`

を置いた。

Editingという語は説明語として使うと、

- editor
- editing operation
- selection / deletion / revision
- purposiveness

を持ち込みやすい。

したがって01Dの監査結果は維持する。

ただし、

> **「編集する」という日常語まで使用禁止にしたわけではない。**

今回の

> **編集する（Cedorbity｜Activity）**

は、内部機構を説明する語ではなく、まだ割れていない中間領域につけた暫定的な呼称。

したがって、

`Naming the Gap ≠ Explaining the Gap`

そして、

`Cedorbity｜Activity ≠ Mechanism of Editing`

を維持する。

---

### 5｜Editusの位置が動いた

今回もっとも大きく動いたのは、むしろ **Editus**。

従来は無意識に、

`Homo edits → therefore Homo editus`

という文法を読み込みやすかった。

つまり、編集する主体と編集機構を先に想定し、その結果としてEditusを名づける構文。

しかし現在の配置では違う。

内部の `[ ? ]` は見えないままでよい。

見えるのは、

- ingestion
- input / trace
- excretion
- output / trace

そして、**排泄されたTrace**。

したがって、

> **Editing? → わからない。**  
> **Editus → 排泄されたTraceによって見える。**

EditusはEditing mechanismを知っているから名づけられるのではない。

> **排泄されたTraceがあるから、Editusが露出する。**

したがって、

`Editus ≠ Proof of Editing Mechanism`

`Editus ≠ Explanation of Editing`

を置ける。

これは01Dの撤回ではなく、01Dで動詞 `Editing` に行った監査を、`Editus` 側にも適用したもの。

---

### 6｜排泄する生命

ここから、以前から使ってきた

> ingestion / editing / excretion

の三項も非対称に見えてくる。

ingestionは境界通過として観察できる。  
excretionも境界通過として観察できる。

しかし、その中間のeditingは同じ仕方では観察できない。

したがって、

> **生命は編集するからEditusである**

と内部機構から定義する必要はない。

むしろ現在観察できる最小形は、

> **生命は摂取する。**  
> **中間には `[ ? ]` がある。**  
> **生命は排泄する。**  
> **排泄されたTraceによってEditusが見える。**

冗談めいているが、

> **排泄する生命。**

は、現在の観察論的位置をかなり正確に保持している。

---

### 7｜01Cとの接続

01Cで最後まで生き残ったのは、

> **The same prior trace does not do the same work after a different subsequent encounter.**

だった。

そして、

> _After comes after Before. But the work of Before is not finished before After._

まで削った。

ここでも、観察できたのは前後と差であり、その内部の因果機構ではなかった。

HOW図から矢印を落としたのは、この作法を記法そのものへ折り返したもの。

`Sequence Notation ≠ Causal Description`
