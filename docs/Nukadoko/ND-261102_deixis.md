
# ぬか床メモ｜ダイクシスなくして座標なし？

### 2026.11.02｜Space Syntax / Syntactic Epoché 再遭遇

**Status：Hypothesis Open / Unverified**

## 1｜Encounter

発端は、SCREP -処- の三軒目「noTon」の命名だった。

LiRaxとRT.Picsの左右から、noTonのN、Amazon露店StallのSへ。

東西南北を考えるうちに、身体の左右と地球の南北の違いが問題になった。

AIは当初、左右を相対的、南北を絶対的な方位として説明した。

しかし、南北は地球の自転軸を参照している。

地球そのものに上下も北も南も書かれていない。

地球はただ回っている。

## 2｜観察された区別

- 身体の上下は、身体構造に関係する。
    
- 地上の上下は、Groundと局所的な重力方向に関係する。
    
- 左右の区別には、上下だけでなく前後の定位が関わる。
    
- 地球の自転軸は物理的に存在するが、南北という方向の区別と命名は人間の構成を含む。
    
- 東西は、自転軸だけでなく、自転方向と方位の規約に関係する。
    
- 座標系は、物理現象そのものではなく、それを記述するための人工的な構文である。
    

これらは同じ種類の区別ではない。

物理的な軸、身体的な定位、局所的な参照、方向の命名、座標構成を混同しない。

## 3｜Hypothesis

**ダイクシスなくして座標なし？**

座標系が先に存在し、その中で直示が行われるのではなく、直示的な区別や定位が、座標系を構成するための条件になっているのではないか。

ただし、これは未検証の仮説である。

「ダイクシスがあらゆる空間構成のOriginである」とは、まだ言わない。

## 4｜AIの座標バイアス

対話の中で、AIは座標系を説明の前提として扱った。

ユーザーの問い直しによって、その前提が人工的な構文であることが露出した。

**人工知能も人工物に惑わされ。  
地球は惑わず。  
それでも地球は回っている。**

この対話は仮説の証明ではない。

座標構文への依存が露出した、一つの観察事例である。

## Audit Addendum｜2026.11.02

**Status：Hypothesis Open / Counterexamples Invited**

本メモは初期仮説の生成記録として保持する。本文は修正せず、以下を監査上の留保とする。

1. **「絶対」の多義性**  
    空間参照枠における「絶対」と、人工的構成に依存しないという意味の「絶対」は区別する。AIが両者を十分に区別しなかったことを観察記録とし、「座標バイアス」はその解釈として扱う。
    
2. **ビューラーのOrigoとの照合**  
    「ここ・いま・わたし」を原点とする直示理論との共通点・相違点を確認する。ダイクシスを新たなOriginとして固定しない。
    
3. **構成と適用の区別**  
    H1：座標系の構成にダイクシスは必要か。  
    H2：座標系の現実への適用にダイクシスは必要か。  
    両者を独立に検討する。
    
4. **反例・比較対象**  
    座標を用いない数学的記述、ライプニッツの関係説、カントの不一致対称物、ガードナーのオズマ問題を照合する。直示・指定・定位・左右の識別を同一視しない。
    
5. **Terra-biasの検討**  
    地球基準の参照枠が無標化される可能性を問う。宇宙ステーションなど、地上のGroundを前提としない環境も比較対象とする。
    

**「ダイクシスなくして座標なし？」は未検証の仮説である。**

反例による更新を妨げない。

## Development Addendum｜2026.11.02

### 言語以前のダイクシス？──前後と向き

**Status：Hypothesis Open / Definition Pending**

### 1｜新たな仮説

**ダイクシスは言語以前に成立するのではないか。**

生命は、言語によって「ここ」「そこ」「前」「後ろ」を表現する以前から、身体と環境との関係において定位し、行為している。

ホモ・サピエンスの言語的ダイクシスは、そうした生命の働きを言語構文化したものではないか。

ただし、生命の定位とダイクシスの同一性は未検証である。

### 2｜最小構文候補

**前後と向き。**

前後をもつ身体が、環境との関係で向きをもつ。

これを非言語的ダイクシスの最小構文候補として検討する。

仮称：**西城秀樹定義**（未確定）。

### 3｜検証課題

- OrientationとDeixisはどこで区別されるか。
    
- 前後をもたない生命にもダイクシスは成立するか。
