## 1．本線：言葉の可塑性は何を可能にし、何を見えなくするか

前半メモによれば、出発点はIvan Illichの『ABC』との関連から遭遇したUwe Pörksen『Plastic Words／プラスチック・ワード』だった。問われたのは、特定の言葉が文脈を横断しながら説明力や専門性を帯びる仕組みと、その移動によって何が説明され、何が説明されなくなるかである。この遭遇経路もメモに基づく再構成であり、両著作の関係は原典で確認する。

Pörksenのプラスチック・ワードを入口に、言葉が異なる場面を移動し、広く通用する過程を考える。問題は抽象語の使用そのものではない。具体的な対象・関係・判断条件が抜け落ちても、専門性や正当性を帯びた言葉として流通し、理解や合意が成立したように見えることを検討したい。

メモでは「システム」「情報」「コミュニケーション」「発展」が例として挙がる。カタカナ語であることは判定基準にせず、漢語・和語にも同じ問いを向ける。プラスチック・ワードは語の種類・属性なのか、使用に現れる働きなのか。この区別は原典確認まで開いておく。

ここで「モジュール式レール」という比喩を置く。規格化された語句は、別の文脈にも接続でき、もっともらしい説明の経路を容易に組み立てる。ただし、**接続できることと、推論が成り立つことは別である。** 継ぎ目で意味が変わっていないか、途中の根拠が省略されていないか、分岐が一つの結論へ誘導していないかを点検する。比喩は分析の補助であり、言語全体を説明する理論にはしない。

前半メモでは、このプラレール比喩がユーザー自身のRail論・Orbit論との接点になったとされる。レールは走れる経路とともに、走れない経路も作る。ただし、比較可能であることから概念の同一性は導かない。Rail論・Orbit論の定義もここでは補作しない。

AIの言説では、流暢な語句の接続が、この「説明ができた感じ」を増幅しうる。観察対象にはAIの応答だけでなく、AIを語る企業・政策・研究の言説も含める。たとえば「支援」「透明性」「責任」は、何を誰に対して行うのかを指定しないまま、望ましい方針への賛同を集める語になりうる。

**戦略的多義性**は、その意味の幅が、異なる期待を一つの表現のもとに結びつけたり、具体的な約束の確定を避けたりする働きとして捉える。ただし、曖昧さだけから話者の意図を推定しない。通常の多義性、説明の省略、意図的な使い分け、結果としての責任回避を区別し、利益や運用の証拠を調べる。

## 2．関連研究との遭遇――継承関係と比較可能性を分ける

| 探索候補（メモ記載） | メモから復元される論点・比較上の注意 |
| --- | --- |
| von Groddeck & Schwarz（2013）、メガトレンドをEmpty Signifiersとして扱う研究（題名未記載） | 意味が十分に固定されない語が、異なる立場・期待を結びつける。意味の不確定性による結集と、プラスチック・ワードの働きを同一視しない。 |
| Jasper Roe、Leon Furze、Mike Perkins、*Digital plastic: a metaphorical framework for Critical AI Literacy* | メモではAI生成コンテンツの生産・流通・残存を捉える比喩として紹介される。言葉の働きとの比較は可能だが、同じ「plastic」から直接の継承関係を推測しない。 |
| Travis LaCroixら、*Strategic Polysemy in AI Discourse* | 「推論」「エージェント」「アラインメント」などの意味の使い分けを検討する候補。広い意味で能力を印象づけ、批判時に狭い意味へ戻るという読みは、本文と実例で検証する。 |
| LaCroixのAI Alignment関連研究（題名・年未記載） | 「誰に対する、何へのAlignmentか」を問う。整合の基準や責任の問題と、用語の多義性の問題を分ける。 |
| Sina Fazelpour、Will Fleisher、*The Value of Disagreement in AI Design, Evaluation, and Alignment* | 判断を平均化・単一ラベル化したときに失われる差異を検討する候補。異論を雑音として処理しないことと、すべての異論を正しいと認めることは別である。 |

ここから前半メモが示す重要な分岐は、**Disagreement as Resource／Disagreement as Locus**である。前者は異論が評価や意思決定の改善に役立つかを問う。後者は、直ちに有用性を示さない異論にも、存在し、再び問い返される場所があるかを問う。Locusという対比表現は会話由来の整理として保持し、参照研究の確立した概念とはしない。ユーザーの「HOW LIBERAL LOCUS?」との接点も、定義と資料を確認する課題として残す。

さらに、**Trace access／Trace efficacy**を分ける。記録を参照できることだけでは、その異論が後の判断や関係に効いたとはいえない。何が変わったか、応答や変更にどんな経路でつながったかを別に追う。

## 3．自己監査――自分たちの理論語彙にも同じ問いを向ける

本線はAI企業や研究者の言説批判で終わらない。Trace、Encounter、TUP、Support、Locusも、文脈を横断する便利さによって、説明を省略する語になりうるかを問う。

「これはTUPである」と名づけるだけでは、何が、どのEncounterをまたいで、どのように変わったかは示されない。「Supportが必要」と述べる場合も、何が何を、どんな条件で支えるかを示す必要がある。これらの語の厳密な定義は未確認なので、本ノートでは新たな定義を与えない。

**理論語彙は使用してよい。しかし、その使用自体を証拠にしない。** 自分たちの語彙にも、対象・根拠・推論・限界・修正条件を問う。同時に、説明できないことから直ちに存在しないとは結論しないし、説明の形式が整っていても正しさは別に検証する。

今回の履歴取得も監査対象になる。「読んだ」と述べるなら、直接読めた範囲、再構成メモで補った範囲、参照できない範囲を区別する。記録へのアクセスと理解の妥当性も別である。

## 4．説明・応答・支援を混同しないための区別

| 区別 | 作業上の着眼点 |
| --- | --- |
| 説明／説明の代用品 | 説明は対象・根拠・推論・限界を示し、問い返しや修正を可能にする。代用品は、名前や評価語で理解を閉じたように見せる。長さや流暢さだけでは判定できない。 |
| 説明可能性／説明責任 | explainabilityは、何がどの程度理解・検証できるか。accountabilityは、誰が誰に応答し、その応答を評価・訂正・救済へどうつなぐか。説明できることだけで責任を果たしたとはいえない。 |
| 異論／同調・賛同／support | 異論は争点を開く。同調者は異論が孤立して消えるのを防ぎうるが、その主張や最終結論への全面的同意とは限らない。supportは、発言機会の保障、情報提供、行動支援など、何を支えるのかを別途指定する必要がある。 |

「同調者問題」と「Support問題」は分けて扱う。同調者問題では、誰かの応答が討論の構図をどう変えるかを見る。Support問題では、支援の対象・手段・条件・帰結を見る。AIが相手を支援すること、相手の主張に同意すること、異論を検討できる条件を整えることは、それぞれ別の行為である。

## 5．討論から決定へ――残ったものも記録する

異論、同調者、討論、決定は、単純な因果系列ではない。異論があっても討論は成立しないことがあり、討論が成立しても結果は変わらないことがある。それでも、決定の理由や当事者の理解が変われば、同じ結果の意味は変わりうる。

したがって、討論の成否を全員一致や発言量だけで評価しない。何を争点として認め、どの理由に応答し、何を決めたのかを追う。前半メモは、ユーザーによる修正として「決定はトータルではない」を伝える。**決定しない部分を決定すること、部分決定、明示的な保留、先延ばし、決めずに残した事項、議題から排除した事項**を区別する。非決定は直ちに失敗ではないが、保留の理由・再検討条件・その間の負担が見えなければ、責任回避にもなりうる。

本線の接続は、次のように置く。

**語の意味と接続を点検する → 説明が問い返しを許すかを見る → 異論への応答を追う → 決定と未決定を記録する → 応答責任の所在を確かめる。**

> 討論が先にあって、言葉の意味があとから変わることもある。  
> 決定が先にあって、説明があとから生じることもある。  
> 非決定が異論を生み出すこともある。  
> 
> **探索の順序 ≠ 対象の構造**。

## 6．別枠の事例研究：2007年の二論文

前半メモに記載された題名は『成熟社会における市民政治』『成熟社会における責任政治』。題名・刊行年を含む書誌と本文は今回未検証である。民主主義・自由主義・討論・決定・責任を扱う独立した政治理論研究として読み直す。

会話では『12人の優しい日本人』をめぐり、最初と最後の「全員一致で無罪」を比較する読みが提示された。同じ結果の間にある異論・同調者・討論・決定を観察することで、結果だけでは見えない民主主義の質的差異を問う。

この事例は本線に接続できるが、AI論の実例としてそのまま回収しない。二論文を当時の問題設定と政治理論に即して読み、その後に現在の問いとの接点を整理する。「最初は低質、最後は高質」と先に評価せず、何を質の基準とするのかも検討する。作者の意図についても、作品の構造から断定しない。

書籍案『一二千万人の日本人のためのやさしい政治学入門』とKDPは保留。現段階では独立した事例研究として置く。

## 7．監査質問

1. **意味**：この語は何を指すか。場面や話者が変わったとき、同じ意味を保っているか。
2. **接続**：結論までの継ぎ目に、根拠の欠落や意味のすり替えはないか。
3. **説明**：何が分かるようになったか。どの問いが未回答で、何があれば説明を修正できるか。
4. **責任**：誰が誰に答えるのか。誤りや不利益が判明した場合、誰が訂正・救済するのか。
5. **異論と支援**：異論は検討されたか、それとも共感的な応答だけで処理されたか。何への賛同・支援なのか。
6. **決定**：決まった範囲はどこまでか。何を保留・排除し、その負担を誰が引き受けるか。
7. **多義性の効果**：意味の幅で誰が何を得るか。その働きを「戦略的」と呼ぶための証拠はあるか。
8. **異論の居場所と効力**：役に立つ異論だけが残されていないか。記録に残ることと、後の判断に効くことを区別できるか。
9. **自己監査**：Trace、TUP、Encounter、Supportなどを、具体的な関係の記述に置き換えられるか。語を取り去っても説明は残るか。
10. **資料と研究間の関係**：直接確認、再構成、仮説のどれに依拠するか。類似性の指摘を、継承関係の証明と取り違えていないか。

## 8．次の研究作業

- **資料を確保する**：会話前半の逐語記録、Pörksen原典、2007年の二論文を揃える。再構成メモとの対応・相違を記録する。
- **探索候補を検証する**：第2節の各文献について書誌、本文、用語の定義、Pörksenへの参照の有無を確認する。題名不明のAlignment研究も特定し、継承関係と比較可能性を別々に記録する。
- **概念を固定する**：プラスチック・ワード、多義性、説明、説明責任、同調者、support、非決定の暫定定義を作り、原典の概念と本ノートの拡張を分ける。
- **小さな比較資料を作る**：AI応答とAIをめぐる言説から短い事例を集め、語・文脈・根拠・応答主体・決定／保留を記録する。同じ抽象語が有効な説明になる反例も含める。
- **改稿の効果を検証する**：対象・主体・条件を明記した書き換えで、検証可能性が増すかを比べる。具体化だけでは解けない争点も残す。
- **自分たちの語彙を比較に含める**：Trace、TUP、Encounter、Support、Locusにも同じ監査質問を適用する。有用性、居場所、参照可能性、実際の効力を分けて記録する。
- **二論文を別表で再読する**：最初と最後の決定、異論への応答、同調者の役割、残された問題を整理し、本線への接続はその後に判断する。
- **制度と実践を追う**：言葉の具体化だけでなく、誰が問い返せるか、応答を求められるか、決定を修正できるかを調べる。討論・決定・説明責任を言語の問題だけに還元しない。

現時点の仮説は、言葉の柔軟な接続が、理解と協働を助ける一方で、問い返しや責任の確定を省略させる場合もある、というもの。自分たちの理論語彙も例外にせず、その境界を具体的な使用場面で確かめる。中心の問いに、**「その違いを、誰が、どのように問い返せるのか」**を加えておく。
