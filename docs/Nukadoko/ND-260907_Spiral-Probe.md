## Spiral Probe｜向きと痕跡

> **Direction without Destination.**  
> **Trace without Rail.**

暫定メモ：

- 自律／他律は属性として置かない。
- 遭遇・離脱／待機・拘束も固定的な位置にしない。
- まず観察するのは**向き（Direction）**と**痕跡（Trace）**。
- 一度の向き ≠ Bias。
- 向きがTraceを残し、re-Encounterで再び向きが現れる。
- 反復する向きから、あとで**Biasが露出することがある**。
- Spiralは動かす力ではない。
- Direction / Trace の反復を振り返ったとき、**巻いて見えることがある**。
- **Direction ≠ Destination**
- **Trace ≠ Rail**
- **Bias ≠ Trait / Cause / Destination**
- **Spiral ≠ Progress / Development / Force**
- 螺旋の半径 ≠ 自由／自律の程度。
- 半径の意味は、まだ決めない。
- 「何が向かいたがるのか？」も、まだ決めない。
