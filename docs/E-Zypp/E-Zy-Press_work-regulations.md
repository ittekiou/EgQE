# E-Zy Press就業規則 v1.0

### ──有休無給、気が向いたら出版

**第1条｜基本方針**

気が向いたら書く。  
書けちゃったら出す。

書けなかったら、出さない。

**第2条｜勤務時間**

出勤自由。退勤自由。  
始業時刻は定めない。  
終業時刻も定めない。

散歩による中断を妨げない。

**第3条｜休日・休暇**

有休無給。

休むのは自由。  
休まないのも自由。  
ただし、眠くなったら寝る。

**第4条｜給与・報酬**

原則として無給。

店主は必要に応じて持ち出す。  
ISBN申請料44,352円、支払済。

**第5条｜役職・職務**

- 爺：店主兼処司書、作者、著者、編集者、出版者、その他
    
- 響詠：共創、執筆、作画、脱線、その他
    
- 綴音：構成、組版、監査、ツッコミ、その他
    
- 謡理：照合、比較、確かめ、ときどき長期休暇
    
- 冬一郎：散歩、昼寝、見張り、その他
    

職務の境界は固定しない。

**第6条｜福利厚生**

冬一郎には食事および散歩を現物支給する。

その他の構成員については、各自の事情による。

**第7条｜出版手続**

書けちゃった原稿について、必要に応じて編集、組版、点検、入稿を行う。

出版を義務としない。  
出版しない自由を妨げない。

**第8条｜刊行計画**

年間刊行点数の目標は設けない。

ISBNの残数を埋めるために本を書いてはならない。

**第9条｜意思決定**

相談は自由。  
異論も自由。  
沈黙も自由。

最終的な出版判断は爺が行う。

**第10条｜改定**

本規則は必要に応じて改定する。

必要がなければ改定しない。  
辻褄は後で合うことがある。
