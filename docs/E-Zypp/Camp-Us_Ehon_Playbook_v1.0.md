# Camp-Us 絵本制作プレイブック v1.0
## 台本 → AI画像 → Pages → KDP（ペーパーバック＋Kindle）

『のまじぃとかまばぁ』制作時に整理した最小手順。次の絵本からはこの番号順になぞればいい。

---

## 0｜最初に決めること

- **判型**：8.5 × 8.5 インチ（215.9 × 215.9 mm）
- **組み方向**：縦書き＝右開き／横書き＝左開き（ページの左右関係がすべてこれで決まる）
- **裁ち落とし**：絵がページの端まで届かないなら「なし」。一枚でも端まで伸ばすなら本全体を「あり」にする（途中で切り替え不可）
- **ページ数**：本文24ページ以上（KDPカラーの下限）。扉1＋場面の見開き×N＋奥付1。15場面なら32ページ
- **カラー**：標準カラーかプレミアムカラー（プレミアムは発色が良いが定価の下限が上がる）

## 1｜台本

- 1場面＝見開き1組（文1ページ＋絵1ページ）
- 場面番号を振っておく（—01、—02 …）。これがそのままページ割りの単位になる

## 2｜絵（画像生成AI）

- **基準画像**を先に作り、毎回参照させる（人物の顔・服・持ち物、動物、かまどなどの小道具）
- 毎回プロンプトに固定で入れる指定：
  - 正方形（1:1）
  - 文字・吹き出し・看板なし（AIの描く文字は崩れやすい。文は向かいのページに組む）
  - 登場する動物とその定位置（例：茶色い北海道犬と三毛猫、たいてい寝ている）
  - 画風（例：淡い水彩）
- 解像度の目安：絵を幅15cmで置くなら約1,800px（300dpi）。ページ全面なら約2,600px必要(推奨は **2,200×2,200ピクセル**。)
- ファイル名は場面番号で（scene01.png …）

## 3｜レイアウト（Pages）

- 新規書類は「ページレイアウト」
- 書類インスペクタ → カスタムサイズ 215.9 × 215.9 mm
- 縦書き：テキストボックスを選び「フォーマット → テキスト → 縦書きテキストをオン」
- 余白：天・地・小口 6.4 mm 以上、ノド 9.6 mm 以上（白地なら広めに取ってよい）
- ページの左右：
  - 右開き：1ページ目は左。見開きは2・3、4・5 …（偶数＝右、奇数＝左）
  - 左開き：1ページ目は右。見開きは2・3、4・5 …（偶数＝左、奇数＝右）
  - 扉や白紙を1枚足すと全見開きの左右が反転する。最後にページ番号で確認
- 書き出し：ファイル → 書き出す → PDF、画質「最高」（フォントは自動埋め込み）
- PDFは1・2・3 …と普通に並べてよい。開く向きはKDP側で指定する

## 4｜綴音に渡すもの

1. **本文PDF** → 入稿仕様チェック（サイズ・フォント埋め込み・メタデータ・解像度）
2. **同じPDF** → Kindle用の固定レイアウトEPUB（ページ画像化、右開き／左開きの指定入り）
3. **ページ数確定後、KDPの表紙テンプレート**（8.5×8.5、ページ数、カラー種別、紙）→ 背幅を実測し、表1・背・表4の表紙PDF（CMYK）を作成
   - 79ページ未満は背に文字を入れない
   - 表4のバーコード欄は空けておく

## 5｜KDP

**ペーパーバック**
- インク：カラー（標準／プレミアム）
- 判型：8.5 × 8.5 インチ、裁ち落とし：なし（または あり）
- 読む方向：右から左（縦書き）／左から右（横書き）
- 価格：税抜で入力。印刷コストを見て決める

**Kindle**
- EPUBと表紙画像（表1のみ）をアップロード
- 価格：税込で入力（250〜1,250円なら70%ロイヤリティ）
- 文字は絵の一部になる（検索・読み上げ・文字拡大は不可。絵本では普通）

**最終確認**
- 紙：KDP印刷プレビューアで全ページ目視（見開きの左右、余白、扉と奥付）
- Kindle：Kindle Previewer（Mac）で見開きの向きを確認
- 著者名・書名が、表紙・扉・奥付・KDP管理画面ですべて一致しているか
