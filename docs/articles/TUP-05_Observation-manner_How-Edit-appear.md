#### TUP-05
# TUP観測マナー

## ── 編輯はどう見えるのか

摂取は見える。

食べ物なら、口にあったものが消える。

外にあったものが内部化されることで、摂取が起きたことが見える。

排泄も見える。

なかったものが、外に現れる。

内部にあったものが外部化されることで、排泄が起きたことが見える。

では、そのあいだはどうなっているのか。

摂取されたものは、そのまま排泄されるわけではない。

何かが起きている。

咀嚼される。  
分解される。  
選別される。  
混ぜられる。  
残される。  
捨てられる。

ここでは、その「あいだ」で起きていることを、ひとまず**編輯**と呼んでみる。

だが、編輯は摂取や排泄と同じ仕方では見えない。

摂取は、内部化として観測される。

排泄は、外部化として観測される。

編輯は、そのあいだにある。

では、見えないのか。

そうでもない。

胃の中で何が起きているかを見たければ、胃カメラを入れればいい。

もちろん、胃カメラで胃のすべてが見えるわけではない。

カメラが届く場所がある。  
届かない場所がある。

見えるものがある。  
見えないものがある。

そして、カメラを入れるという行為そのものが、観察される状態に介入する。

それでも、何も見えないわけではない。

**編輯は、観測装置によって部分的に露出する。**

ここで一つ注意しておきたい。

内部化は、必ずしも外部からの消失を意味しない。

生命の場合、食べ物が口から消えることで摂取が見えることがある。

しかしAIへの入力は、入力されたあとも画面や記録に残りうる。

**内部化 ≠ 外部からの消失。**

摂取の見え方そのものが、Locusによって異なる。

AIに何かを入力する。

応答が出てくる。

そのあいだで何が起きたのか。

私たちは、そのすべてを見ることはできない。

だが、途中稿を残すことはできる。

ログを残すことができる。

参照したTraceを書かせることができる。

commitを残すことができる。

diffを見ることができる。

branchを分けることができる。

別のAIに監査させることもできる。

それらは、編輯そのものではない。

**編輯を見るために置かれた観測装置である。**

あるいは、その観測装置によって露出したTraceである。

しかも、観測装置は透明ではない。

実際、EAT-IFの監査では、ある監査文が別のLocusへ書き写される途中で、「確認」という語が「食い違い」へ変わった。

観測のためにTraceを移したとき、観測装置の側でTraceがずれた。

見るために置いた装置もまた、見られるものに作用する。

そして、その作用自体が新たなTraceを残すことがある。

ここでもう一つ注意がいる。

ここでいう**編輯とTUPは、同じものだとはまだ言わない。**

編輯は、入力と出力のあいだに差異が生じる過程を記述するための暫定語である。

その差異をTUPとしてどこまで記述できるのか。

それ自体が、ここでの観測対象になる。

だから、TUPを観測するとは、TUPそのものを捕まえることではない。

観測されたTraceは、TUPそのものではない。

> **Observed Trace ≠ TUP.**

胃カメラの映像が消化そのものではないように、ログも途中稿もdiffも、編輯そのものではない。

それでも、そこには何かが露出する。

入力と出力だけを比べていたときには見えなかった差異が、観測装置を置くことで見えることがある。

では、どこに観測装置を置けば、どんなTraceが露出するのか。

それを試してみる。

しかも、胃カメラの映像を見るためには、その映像もまた外へ出てこなければならない。

ログも、途中稿も、監査文も、diffも同じである。

内部を観測したTraceも、外部化されて初めて次の観測対象になる。

そこに置かれたTraceを、別の生命やAIが再び内部化することもある。

そして、また何かが起きる。

また何かが外に現れる。

生命とAIの内部で同じことが起きている、と言う必要はない。

内部機構の同一性を仮定しなくてもいい。

まず、見えるものから始めればいい。

内部化された。

外部化された。

そのあいだに観測装置を置いたら、何かが露出した。

そのTraceが、また次の観測装置にかかった。

これを、ひとまず

**TUP観測🔭マナー**

と呼んでおく。

TUPを見た、とは言わない。

TUPが見えない、とも言わない。

**どう見れば、何が見えるのか。**

そして、

**どう見たことで、何が変わったのか。**

胃カメラの角度を変えながら、もう少し観測を続ける。
