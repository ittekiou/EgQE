## 01｜四つの問いの原文照合

| Xenaの問い | P02の共同声明における基準 |
|---|---|
| Q1. Does the Lean statement match the informal statement? | リーマン予想の命題が正しい |
| Q2. does the code compile? | Alpögeのライブラリが正しくコンパイルされる |
| Q3. does the code prove the theorem as stated? | コードが正しい命題を証明している |
| Q4. does the code exploit a bug in Lean’s official kernel? | Leanによる証明が妥当である |

また、第三の問いでは、命題の意味が大量のコードによって変更されていないか、追加の公理が導入されていないかという問題も提起されている。

P02に残されていた原文照合は、これで行えた。

## 02｜この四つの問いは、何に対して立てられたのか

記事の冒頭では、OpenAIが公開した大量の数学論文とLeanコードが取り上げられている。

Xenaは、Leanコードが付属していることだけで論文が正しいと判断する立場と、カーネルにバグがありうるためLeanによる検証には大した意味がないとする立場の双方を取り上げている。そのうえで、四つの問いを提示している。

したがって、この四つの問いは、今回のリーマン予想の証明発表に対する事後的な応答ではない。先行する数学的営みのなかで生まれた問いが、後続する別の数学的営みの検証基準として用いられている。

ここには、グラウンドの形成と作動についての一つの痕跡がある。

## 03｜証明と、証明について書かれた文章

四つの問いのあとに、One final remarkという節がある。Leanコードがすべての検査を通過しても、対応するPDFに正しい証明が書かれているとは限らない、と述べている。

さらに、数学者がAIを用いてLeanの証明を英語に戻し、論証を読もうとしているという話も出てくる。

これはP01のAlpögeが、巨大な文書を公開せず、Leanだけを提示したこととも比較できる。

**証明を書くことと、証明について書くことは違う。**

そして、形式化された証明を自然言語に戻すことも、また別の営みである。

ここでは、次の三つを区別しておく。

- Xenaが推奨した検証方法。

## 響詠の端材メモ

検証者を検証するという問いは、われわれが外から持ち込もうとしていた問いでもある。しかし、すでに数学者やLeanの利用者たちのやり取りのなかにも、その問いが現れていた。しかも、リーマン予想の証明発表より前に。

第八篇の仮題は「誰が検証者を検証するのか。」だった。その問いを立てたのは、われわれだけではなかった。

**グラウンドの上で、グラウンドについての議論が始まっている。**

最初は、リーマン予想が解かれたというFacebookの文章を一つ拾っただけだった。そこから証明の発表文、共同声明、検証記録へと遡った。すると、共同声明が参照した先行記事があり、その記事のコメント欄から、さらに先行する検証器の研究と1997年の論文への道が伸びていた。

グラウンドは、試合が始まる前からあった。しかし、グラウンドについての議論もまた、そこで行われる営みの一部だった。

**グラウンドを調べるという営みも、グラウンドの来歴をつくっている。**
