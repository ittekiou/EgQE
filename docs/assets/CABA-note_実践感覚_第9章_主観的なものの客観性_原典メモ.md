# 『実践感覚』第一部「理論理性批判」第九章「主観的なものの客観性」原典メモ (p.222-234)

## p.222-223 【★社会物理学/社会現象学の二重の真理、批判の導入】
章冒頭。個人・集団には二種類の属性がある——物理的世界の物と同じように数えあげ測定できる「物質的な属性」と、相互関係の中で(弁別的属性として)知覚・評価される「象徴的な属性」。この二重性が社会科学に「客観主義の経済至上主義」対「社会現象学」という二者択一を強いる。

「社会物理学」(客観主義の完成形)は資本の配分を、弁別的記号への分析を通して物質的属性と同じ属性として記録・解読するが、そこで「社会秩序」を、クラス分けする・される判断を加算した集合的クラス分けへ還元してしまう——行為者自身がその判断について抱く(演劇的)表象を見落とす。

「社会現象学」の方は行為者の知覚の微分的差異(弁別的記号による知覚)を懸命に把握しようとするが、力関係の力学と意味関係の現象学の対立は際立ってこそ見えるが厳密さを欠く。マルクス主義理論は前者、行為者の知覚・行為に全く依存しない客観主義的な階級決定原理の数々(経済至上主義の面)に近い。

→ CABA-05C(Relation≠Ground)の議論と直接つながる導入部。物質的属性/象徴的属性の二重性そのものが、後段の階級=分類闘争論の土台になる。

## p.224 【★象徴資本のrente de distinction、弁別化の限界価値低下】
象徴資本(rente de distinction=卓越化のレント)を保証する属性の価値を形成するのは、実践や財の内在的特性ではなく、それらの数の関数(限界価値)——増殖・流布に伴い必然的に低下する。象徴資本の保持者は各々が「仮借ない競争者」でありながら「最高判事」でもある(狼deus/神lupusという古い二者択一の言葉で言われる)。直接の上位集団に同一化するため、あるいは下位集団から自分を区別し続けるために、闘争する以外に道はない。

## p.225 【★プルーストのサロン・スノビズム例】
プルーストが描くサロン/スノビズムの世界が、象徴闘争の良質な例証。サロンの威信は受け入れられた人物の「質=身分(qualité)」に左右され、この「質」自体も受け入れるサロンの「質=地位」によって測られる——循環的な相互構成。社交界の価値取引市場での株の上下は、この二つの規準によって、事情通の目を要する微細なニュアンスによって測られる。

## p.226 【★闘争は無から差異を創出する/近接性のパラドクス】
外部の観察者には均質に見える場でも、その内部で展開する闘争は無から差異を創出する——これは保守的な歴史哲学(リベラル派のエントロピー的「水平化」観念や、階級闘争が減少するという中流階級拡大論)への決定的な反証になる。「労働者階級のブルジョア化」論も同じ「平均」「大衆」への均質化という夢に養われている。

「社会空間内部の客観的な最小距離は、主観的な最大距離と一致することがある」——**最も隣接した者が、社会的アイデンティティ(差異)を一番脅かすものだから**、数ある中で。境界を接する隣接者との微分的差異を全か無かの絶対的差異に変えてしまう傾向。例:法定相続人と非嫡出子、第二子、クラストップの合格者とトップ落第者など、識別できない二者の間に絶対的かつ耐久的な区別を設ける効果。

→ これは**近接性のパラドクス**として、CABA全体にとってかなり重要な一節だと思われる——「似ている≠同じ」の暴力的・制度的な裏面。階級境界での闘争が最も苛烈になるのは、まさに差異が最も微分的で消えかけている場所においてである、という逆説。

## p.227 【★階級化されたアイデンティティの闘争、隣接者への一線】
象徴的闘争は、対象の闘争(実際の競争相手との間の闘争)には尽きず、クラス分けの内部で「暗黙の承認」がある位置を変えようとする闘争でもある。この闘争は階級を構成するのと同じ諸原理に沿ってなされる——それゆえ隣接者に対して一線を画する傾向が、闘争の限界(制度化・儀礼化された指標:称号、貴族や学校の資格、聖別された称号)を見たようになる。

## p.228-229 【★区別の制度化、身体化された「気品(distinction)」】
「ステイタス集団」は結合と分離という社会論理の基礎的な二操作(区別の制度的な形態を与える)を経由して、稀少性・序列を眼に見えるようにする。区別の制度化は「事物・制度が持つ堅固で耐久性のある現実への組み込み」に向かう最も確実な道——弁別に役立つ身心の構えは幼年時代の初期から自明のものとして受け入れられ獲得される時に、自然に区別される=気品のある(distingué)ものとなる。

区別=気品(distinction)の金利(rente)は、最高の区別=気品を持った考えが最も稀少で、それゆえ最高の「生産コスト」に結びついているという事実によって倍加される——自然だと言う言い方、つまり最も統計的に頻度の高い心的傾向との弁別的(distinctif)関係にある。

→ Distinction第3章(p.264-267)の「趣味/生活様式」論と直接接続する一節。区別=気品が「身体化された必然」として幼少期に刻み込まれる、という論点が、ここでは「制度化」の視点から補強されている。

## p.230 【★★ステイタス集団=否認された合法化された支配階級(Weber批判)】
「マックス・ウェーバーがそう思っていたのとは違って、階級とは異なる種の集団なのではなく、否認され、それゆえに合法化された支配階級に他ならない。」

→ これはBourdieuのWeber批判の核心的な一文。ステイタス集団(Status group)は階級とは別種の実体ではなく、階級が「否認(méconnue)」というヴェールを通して合法化された姿である、という強い理論的主張。

続けて:機械的客観主義に反対して、象徴の諸形式は固有の論理と有効性を持っており、分配の中で把握された客観的諸条件に対する相対的な自律を持つ、と表明しなければならない。しかし限界効用説をとる主観主義に対しても、社会秩序は投票や市場価格の総和のように個人の判断の単なる総和で形成されるのではないことを想起させなければならない——支配する者たちが自分たちの生産物に最も有利な優先階梯を押しつけることができる(学校制度のような公式の序列を確立・保証する制度の事実上の準独占権を彼らが持っているから)。

## p.231 【★プルースト引用、社会物理学とハビトゥスの弁証法】
プルースト:「我々の社会的個性は、他人たちの考えの創造物である。」——社交界を牛耳るシャルリュス、ゲルマント公爵夫人らの象徴資本は、軽蔑や拒絶、冷淡さや執心、承認や価値下落の証しであり、尊敬と軽蔑のマークであり、要するに交錯する判断のゲーム全体を前提としている。象徴資本は、城や地所の所有、貴族号、学位のような客観的で平板な現実を魅惑され神秘化された現実に変える形式であり、この知覚がスノビズムをその本義において定義する。

社会物理学と社会現象学の二者択一を乗り越えるとすれば、それは物質的諸属性からなる物質的宇宙が示す規則性と、ハビトゥス(それにとって/それによって社会的世界が存在する)——ハビトゥスのクラス分け図式と、階級の客観的諸条件との間に成立する弁証法的な関係——の産物である社会的世界の規則性の産物である。

## p.232 【★★物質的論理と象徴論理の対立、méconnaissanceの定義】
ハビトゥスが知覚する表現である諸属性は、所有権獲得のための差異を持った能力を(資本を)象徴化する。物の物質的論理と(価値という語をソシュールが使うその用法が集めている)区別の象徴論理との対立は、力の関係にしか注意を向けない社会力学と、意味の関係にしか注意を向けない社会サイバネティクスとの間の対立の原理をなし、かつ同時にこの対立を乗り越える原理をもなす。

象徴的次元の闘争は客観主義の経済至上主義が考えているより遥かに有効であり(純粋な社会限界効用説が望むより遥かに有効性が低い)、分配と表象との関係は、たえざる闘争の所産でありその賭金でもある——分配の仕方を転覆することに利益を持つ者たちと、それを保守することに利益を持つ者たちの間で行なわれる。

「誤認とは、自分が再生産しているものを自分が生産していることを知らず、その物に自分たちが従っている権力を与える無数の信用操作の産物でしかない物-認識である。」

→ これはCABA-08「誤認」概念の核心的定式。誤認は単なる認知的錯誤ではなく、**自分自身が生産している権威を、自分では生産していないものとして経験する**、信用操作(credit-granting operations)の集積そのものである。カリスマ論(次段)への布石。

## p.233 【★★象徴資本=変装したカリスマ(Weber批判、続)】
「象徴資本とは、マックス・ウェーバーがカリスマと呼んだものを指す別な方法だということになる。」——宗教社会学は権力社会学の一章にすぎない(それも小さくない一章)ということを、Weber自身は理解していながら明示的に理論化しなかった。

カリスマとは、承認/誤認の所産である合法性の別名である。信仰は「それによって権力を行使する人物が威信を備えることになる」——欠陥を持った背教の恐怖にたえず取り憑かれている信者たちの心的傾向(すなわち芸術・教養・文学・オート・クチュールその他のフェティッシュに支配された審美的諸権力)であり、彼らはその権力執行者たち(=デザイナー・画家・作家や批評家)によって支配されている。

「対象を聖別する権力=能力(pouvoir)が問題であれ、権力執行者にその権力を投げる者たちの表象を変様させる権力=能力が問題であれ、〔同じことが〕そうである。」

→ Cedorbity-CABA的に見ると、この「カリスマ=誤認の産物」という定式は、権威/正統性の生成過程そのものを扱っており、CABA-08「Word ≠ Concept」の議論(語が概念としての中身を持つかどうかも、この種の信用操作/集合的承認の効果ではないか、という自己適用の可能性)と響き合う。

## p.233-234 【★社会的世界=暫定的均衡、分類闘争こそが対象】
「社会的世界の各々の状態は、暫定的な均衡、動態の一モメントである。」身体化もしくは制度化された分配とクラス分けの仕方の調整がたえず破れ、たえず回復される。分配の本源そのものにある(不可分に稀少な財の所有権獲得のための)闘争は、力関係の永続化や転覆に自分自身の有効性によって貢献しうる表象を強要するための闘争でもある。

クラス分類は、さらには社会階級の概念自体も、分配を決定しその再生産を保証する客観的メカニズムの有効性に対して、この二つ(客観的メカニズムと分類=概念)が構造化する精神を持つ人々の一致がもたらす強化を加えることによって社会階級の生存に寄与する。この一致がなければ、分類と階級概念が(階級)闘争のかくも決定的な賭金となることもなかろう。

現実を保守すること、もしくは変革することをめざす個人的かつ集合的なすべての闘争、そしてとりわけその賭金が現実の合法的定義の強要である闘争(=クラス分類・社会階級の概念をめぐる闘争)であり、その厳密に象徴的な有効性が既成の秩序の保守や転覆に寄与しうるような闘争を包括する現実、これこそ社会科学の対象に他ならない。

→ 章の結語。物質的分配と象徴的分類の弁証法という、この章全体の主題が「これこそ社会科学の対象」という強い宣言で締められる。CABA全体(Activityという語自体の分類闘争を監査する、というメタ的立場)とも構造的に響き合う一節。
