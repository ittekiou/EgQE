# 『ディスタンクシオン』第3章「ハビトゥスと生活様式空間」原典メモ

## p.261 【★habitus=身体化された必然/分割原理としてのhabitus】
「なす階級分割〔クラス分け〕は、行為者が生産する分類可能な慣習行動と、彼らが他人の慣習行動や自分自身の慣習行動にたいして下す類別的判断とに共通の根ざしとつながってゆくのだ。ハビトゥスとはしんじつ客観的に、分類可能な慣習行動の生成原理であると同時に、これらの慣習行動の分類システム(分割原理 principium divisionis)でもある。表象化された社界、すなわち生活様式空間が形成されるのは、このハビトゥスを規定する二つの能力、つまり分類可能な慣習行動や作品を生産する能力と、これらの慣習行動や生産物を差異化=識別し評価する能力(すなわち趣味)という二つの能力のあいだの関係においてなのである。」
→ これが英語文献でよく引かれる"principle of classification" / "system of classification (principium divisionis)"の一節、原文確認できた。

「ハビトゥスとは身体化された必然、つまり道理にかなった慣習行動を生成し、またこうして生みだされた慣習行動に意味を与えることのできる知覚を生成する性向へと転換された必然であって、それゆえ全般的でありかつ他の分野に転移可能な性向として、現に所有されている諸特性の習得条件に固有の必然性を、直接に獲得されてきたものの範囲を越えて、体系的かつ普遍的に適用することができるようにするものである。」
→ 「身体化された必然(necessity turned into disposition)」──実践感覚のfaire de nécessité vertu(p.85)と直接つながる一節。

## p.260
社会空間は行為者たちが構築する抽象的表象(地図のような俯瞰的視野)であり、日常生活の実際の空間との関係は幾何学的空間と日常体験のホドロジー的空間との関係に類比できる──社会空間の客観性は行為者たちがそこで占めている位置、しばしばこの空間を変容させようとする意志や保持しようとする意志によって左右される視点をもっているということである。

## p.263 【★ハビトゥス=構造化する構造/構造化された構造、階級的存在の対立原理】
「ハビトゥスは構造化する構造、つまり慣習行動および慣習行動の知覚を組織する構造であると同時に、構造化された構造でもある。なぜなら社会界の知覚を組織する論理的分割原理とは、それ自体が社会階級への分割が身体化された結果であるからだ。」
存在状態の体系(差異の体系、差異を表わす位置の体系)における位置づけしだいで決まる相対的諸特性──社会的アイデンティティは差異のなかで規定され明らかになる。「もっとも基本的な対立(身分が高い/低い、金持/貧乏、など)は、慣習行動および慣習行動の知覚の基本的な構造原理として働く傾向がある。ハビトゥスは慣習行動を生みだす図式の体系であり、階級の存在状態に固有の要請と…」

## p.264(図8) 【★★★habitus公式の図式版、確認】
「図8」というタイトルの生成モデル図。矢印(知覚・評価行為)と二重矢印(条件づけ)で構成される:
生活条件1(条件づけの集合)及び(構造化する構造としての)さまざまな生活条件の構造における位置 ⟹〔条件づけ〕 構造化されかつ構造化する構造としてのハビトゥス1 → { 分類可能な慣習行動または作品の生成図式の体系 ; 知覚・評価図式の体系(単数形の「趣味」) } → 分類可能な慣習行動及び作品 = 分類されかつ分類する慣習行動すなわち弁別的記号の体系としての生活様式1(複数形の「趣味」)
(生活条件2→ハビトゥス2→…生活様式2、生活条件n→以下同上、と繰り返される)
→ これが英語文献でしばしば言及される「[(habitus)(capital)]+field=practice」の実質的な内容にあたる図(図8)だと考えられる。ただし、この見開きでは代数記号そのもの(「capital」「field」という語や「+」「=」の数式的表記)は使われておらず、「生活条件」(=資本の量と構造によって規定される位置)→ハビトゥス→慣習行動/生活様式、という散文的な生成モデル図として提示されている。英語版の該当箇所(p.101前後)に、この図と対応する形で代数的な速記表現が脚注か本文にあるかもしれないが、この見開き範囲には確認できなかった。

## p.265
ハビトゥスの体系性は作り出す方法のうちにあるがゆえに、作り出された作品のうちにも宿っている──文字の「筆跡」の比喩(同じ人が紙に書いても黒板に書いても、万年筆でもチョークでも、その人の書き方だとすぐ分かる、様式上・手法上の特徴の類推作用)。家屋・家具・絵画・書籍・自動車・アルコール・煙草・香水・衣服など、個人・集団をとりまくものの全体のうちに、あるいはスポーツやゲーム、教養娯楽など、個人や集団がそれを通して自らの卓越性を顕示しようとするもろもろの慣習行動のうちに(物質的にも象徴的にも)「特性=所有物」として宿っている。

## p.264続き 【★★habitusは資本配分を象徴的差異の体系へと変貌させる「錬金術」】
「(ハビトゥスの所産としての)慣習行動のあいだの差異という…力関係の最終結果である資本の配分を、知覚された差異と弁別的特徴の体系へ、すなわちその客観的な本当の姿においてはとらえられていない象徴資本・正統的資本の配分へと変貌させる錬金術の基本にあるものなのだ。」
続けて、modus operandi(作りだす方法)とopus operatum(作りだされた作品)の対比──ある一人の行為者がおこなうすべての慣習行動や仕事は、同一の構造化する構造(作りだす方法)が生みだす多様な構造化された生産物であり、たがいに一貫性を探そうとしなくても客観的に調和している。ハビトゥスはたえず実践レベルでのメタファーを生みだす。
→ これが英語文献で「[(habitus)(capital)]+field=practice」として要約される内容の、散文における最も直接的な等価表現だと思われます。資本の配分(力関係の結果)がハビトゥスという錬金術的変換装置を通り、知覚された差異=象徴資本の体系(=生活様式/趣味という実践)として立ち現れる、という構図そのものです。

## p.266-267
p.266: ハビトゥスは生活様式(家具・衣服・話し方・身のこなしなど、下位象徴空間の各々に固有の論理のうちに一貫した同一の表現意図を表わすさまざまな弁別的選好の統一体)の根本にある生成方式。老家具職人の例(仕事ぶりに見られる倫理観と作品の美しさを判定する美学が「仕事のための仕事」という同一の性向のうちにそのまま現われている)。よく調和した諸特性の体系(「似合いの夫婦」「同じ趣味を持つ友人」等)は分類図式の体系である趣味をその原理としているが、これらの分類図式は生活様式が社会階級の上層部になるほど重要性を増す。

p.267 【★趣味の定義──差異を象徴的差異へ変換する作用因】
「趣味とは、事物から判明にして弁別的な記号への、すなわち連続的分布から非連続的対立関係への転換を操作する、実際上の作用因である。それは物体の物理的秩序のなかにしるされている差異を、意味をもつさまざまな区別の象徴的秩序へと接近させる。つまりそれは、客観的に分類された慣習行動……を、分類する慣習行動へ、すなわち階級の位置の象徴的表現へと変容させる……。この分類体系は、社会空間内において一定の位置を占めるという経験を通して現われてくる社会空間構造が身体化された結果出てくるものである。」
→ 「趣味」がhabitusの評価的側面として、客観的差異(資本配分の結果)を象徴的差異(弁別的記号・生活様式)へと変換する「作用因」として定義される──p.264の「錬金術」論とセットで、公式の実質内容をなす一節。

## p.269 (文化消費空間の二次元モデル、要点)
文化消費空間の構造と変化を支配する二つの対立軸: (1)経済資本・文化資本ともに最も恵まれた階層の消費(希少性による「上品な」消費) (2)経済資本・文化資本ともに最も恵まれない人々の消費(「通俗的〔下品な〕」消費)。両者の中間に、上昇志向をもつ慣習行動(野望と実際に可能なことの間のギャップ)。支配者の観点からは、強いられた禁欲と根拠のない放任主義の組み合わせによって特徴づけられているように見える被支配者の存在状態にたいして、芸術作品と実的性向がその最も完全に近い実現形態である支配者の美学は、ゆとりと禁欲の組み合わせ(熟考の上での抑制、手段の節約・保留・節度)としての選択的禁欲主義を対置する──資本構造の内容(経済資本優位か文化資本優位か)によってさらに明確に特定されてゆく。

## 図8について(まとめ)
探していた「[(habitus)(capital)]+field=practice」という代数記号そのものは、今回読んだp.259-269の範囲には見当たりませんでした。ただし、その内容に相当するものとして:
1. 図8(p.264見開き)──生活条件(≒資本の配分)⟹ハビトゥス→(生成図式+知覚評価図式)→慣習行動=生活様式、という生成モデルの図式
2. p.264の「錬金術」の一節──資本配分をハビトゥスが象徴的差異の体系へと変貌させる、という散文的記述
3. p.267の「趣味」の定義──差異を象徴的差異へ変換する作用因としての趣味
の三つが揃っており、実質的な理論内容は確認できたと考えます。英語版で言及される代数記法自体は、二次文献側の要約・記憶術的表現である可能性があり(調査時にもそう注記されていました)、Bourdieu自身の印刷された文章そのものではないのかもしれません。
